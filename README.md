# AI Agent Project

A Python AI agent project built as part of a guided [Boot.dev](https://www.boot.dev/) course.

## About

This repository contains the code and exercises developed while learning how to build an AI agent. It is intended as a hands-on learning project and may evolve as new lessons and features are completed.

## Tech Stack

- Python

## Getting Started

### Prerequisites

- Python 3.8 or newer
- Git

### Installation

Clone the repository and move into the project directory:

```bash
git clone https://github.com/abood190-c/ai-agent-project.git
cd ai-agent-project
```

If the project includes dependencies, install them with:

```bash
pip install -r requirements.txt
```

## Running the Project

Run the appropriate Python entry point for the current lesson or project stage. For example:

```bash
python main.py
```

> The project structure and entry point may change as the Boot.dev guided project progresses.

## Project Structure

The repository is organized around the exercises and implementation steps from the Boot.dev course. Check the source files and lesson-specific instructions for details about each component.

- Understand the components of an AI agent
